# Python Collections Comparison

| Data Structure | Syntax Example | Ordered | Mutable | Allows Duplicates | Access Method |
|---|---|---|---|---|---|
| List | ["apple", "banana", "apple"] | Yes | Yes | Yes | By index: fruits[0] |
| Dictionary | {"name": "Noah", "age": 25} | Yes, insertion order | Yes | Keys: No; Values: Yes | By key: person["name"] |
| Set | {"apple", "banana", "orange"} | No | Yes | No | No indexing; use a loop or check membership with in |
| Tuple | ("apple", "banana", "apple") | Yes | No | Yes | By index: fruits[0] |
